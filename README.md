# Windows Security Monitoring Lab

## Project Overview

A beginner-level hands-on project demonstrating Windows security monitoring, configuration review, event analysis, and basic security investigation.

## Objective

Develop practical skills relevant to entry-level IT Support and cybersecurity roles by inspecting Windows security features and investigating system events.

## Tools Used

* Windows 11
* Windows Security
* Microsoft Defender Antivirus
* Windows Defender Firewall
* Windows Event Viewer
* GitHub

## Skills Demonstrated

* Antivirus and threat protection monitoring
* Firewall configuration review
* Windows system and security event analysis
* Basic security investigation
* Identifying configuration weaknesses
* Technical documentation

## Labs Completed

1. **Windows Defender Review** — Inspected antivirus protection and security settings.
2. **Windows Firewall Monitoring** — Reviewed firewall status across network profiles.
3. **Event Viewer Analysis** — Examined Windows system and security events.
4. **Basic Security Investigation** — Documented findings and recommended actions.

## Project Structure

* `README.md` — Project overview and documentation.
* `evidence/` — Screenshots and findings from each lab.

## Conclusion

This project provided hands-on experience reviewing Windows security controls, examining system events, identifying potential security concerns, and documenting investigation findings.

No confirmed malware infection or unauthorized access was established during the investigation.
