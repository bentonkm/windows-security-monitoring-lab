\# Lab 1: Windows Defender Security Review



\## 1. Objective



Review Microsoft Defender Antivirus and Windows security settings to assess the computer's basic security configuration.



\## 2. Tools Used



\* Windows Security

\* Microsoft Defender Antivirus

\* Windows 11



\## 3. Findings



\### Antivirus Protection



\* No current threats reported.

\* Real-time protection enabled.

\* Cloud-delivered protection enabled.

\* Automatic sample submission enabled.

\* Tamper Protection enabled.



\### Security Intelligence



\* Security intelligence reported as up to date.

\* Version: 1.463.41.0.

\* Last update: October 30, 2026.



\### Reputation-Based Protection



\* Check apps and files: Enabled.

\* Microsoft Edge SmartScreen: Enabled.

\* Phishing protection: Enabled.



\### Potentially Unwanted App Blocking



\* Potentially unwanted app blocking was disabled.

\* This was an intentional user configuration to allow an application installation.

\* This reduces protection against potentially unwanted applications.



\## 4. Conclusion



Microsoft Defender reported no current threats, and most reviewed protection features were enabled.



The main security configuration concern identified was disabled potentially unwanted app blocking.



No malware infection was established during this review.
