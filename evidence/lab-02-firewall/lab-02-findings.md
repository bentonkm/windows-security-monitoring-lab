\# Lab 2: Windows Firewall Monitoring



\## 1. Objective



Inspect Windows Defender Firewall and review the security status of available network profiles.



\## 2. Tools Used



\* Windows Security

\* Microsoft Defender Firewall

\* Windows 11



\## 3. Findings



| Network Profile | Firewall Status |

| --------------- | --------------- |

| Domain          | ON              |

| Private         | ON              |

| Public          | ON              |



\### Active Network



\* Active profile: Public

\* Connected network: Wi-Fi

\* Firewall status: ON



\### Incoming Connections



\* Block all incoming connections: Disabled (unchecked).



\## 4. Conclusion



Microsoft Defender Firewall was enabled across all three network profiles.



The computer was actively using the Public network profile during the inspection.



No firewall configuration changes were made.



\## 5. Skills Demonstrated



\* Windows Firewall monitoring.

\* Network profile identification.

\* Firewall configuration assessment.

\* Security documentation.
